# Airline Tweet Sentiment Analysis (NLP)

This project explores Natural Language Processing (NLP) techniques using airline-related tweets. It analyzes tweet sentiment, prepares and cleans text, builds text features, trains machine-learning models, and evaluates their performance.

## Project File

- `NLP_PR1.ipynb` — Jupyter Notebook containing the complete analysis and implementation.

## Dataset

The notebook expects a CSV file named **`Tweets.csv`** in the notebook's working directory.

The analysis uses these columns:

- `text` — tweet content
- `airline_sentiment` — sentiment label
- `airline` — airline mentioned in the tweet

Make sure `Tweets.csv` is available before running the notebook. The dataset is not included in this repository unless you add it separately.

## Requirements

The notebook uses Python and the following main libraries:

- pandas
- NumPy
- Matplotlib
- Seaborn
- NLTK
- scikit-learn
- Gensim
- joblib

Some notebook cells also install or use spaCy, TextBlob, WordCloud, Transformers, and Datasets. Install the libraries needed by the cells you intend to run.

```bash
pip install pandas numpy matplotlib seaborn nltk scikit-learn gensim joblib
pip install spacy textblob wordcloud transformers datasets
```

## How to Run

1. Clone or download this project.
2. Place `Tweets.csv` in the same folder as `NLP_PR1.ipynb`.
3. Install the required Python libraries.
4. Open the notebook using Jupyter Notebook, JupyterLab, or VS Code.
5. Run the notebook cells from top to bottom.

The notebook downloads some NLTK resources during execution. An internet connection may be required for those downloads and package installation.

## Project Workflow

### 1. Dataset Inspection and Exploratory Data Analysis
- Load and inspect the airline tweet dataset.
- Check missing values and duplicate records.
- Explore sentiment distribution and sentiment by airline.
- Examine tweet-length distribution.
- Identify examples of common NLP challenges such as negation, sarcasm, slang, misspellings, emojis, special symbols, and ambiguous sentiment.

### 2. Text Cleaning and Preparation
- Practice regular expressions for URLs, mentions, hashtags, numbers, punctuation, and repeated whitespace.
- Create and apply a `clean_text()` function.
- Tokenize tweets.
- Remove English stop words while preserving important negation words.
- Compare vocabulary statistics before and after cleaning.

### 3. Sentiment Analysis
- Implement a dictionary-based heuristic sentiment analyzer.
- Apply VADER sentiment analysis.
- Compare predictions with the actual sentiment labels.
- Evaluate the approaches using accuracy, precision, recall, F1-score, classification reports, and confusion matrices.
- Inspect incorrectly classified examples.

### 4. Text Representation
- Build Bag-of-Words representations manually and with `CountVectorizer`.
- Calculate TF-IDF manually and with `TfidfVectorizer`.
- Explore unigram and bigram features.
- Compare vocabulary sizes and feature limits.

### 5. Word Embeddings
- Train Word2Vec Continuous Bag of Words (CBOW) and Skip-gram models.
- Find similar words and calculate cosine similarity.
- Visualize word embeddings using PCA.
- Convert tweets into document vectors.

### 6. Machine-Learning Models and Evaluation
- Build a TF-IDF and Logistic Regression baseline.
- Compare multiple text-based feature/model approaches with a Word2Vec-based approach.
- Compare Macro-F1 scores.
- Perform stratified cross-validation.
- Analyze classification errors.

### 7. Model Saving and Prediction
- Save the selected pipeline as `sentiment_model.joblib`.
- Reload the saved pipeline.
- Clean new example sentences and predict their sentiment.

### 8. Part-of-Speech Tagging
- Apply POS tagging to selected tweets and ambiguity examples.
- Examine POS-tag distributions by sentiment.
- Visualize frequent adjectives.

## Output

When the relevant notebook cells are executed, the project creates tables, plots, evaluation reports, and a saved model file:

- `sentiment_model.joblib` — trained sentiment-classification pipeline.

The saved model is generated by the notebook; it is not automatically included with the notebook.

## Notes

- Run cells in order because later sections depend on variables and objects created earlier.
- Results may vary if the dataset, library versions, or execution environment differ.
- The notebook sets random seeds for some reproducibility.
- This is an educational NLP project for exploring sentiment analysis and text-processing methods.
